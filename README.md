Entry for the [make.fun bounty "The Funniest Sick-Day Excuse"](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

## The line

> Can't come in today — I sneezed so hard my back filed for sick leave too.

One line, 73 characters. A sneeze hurts the back, so the back calls in sick
too — half believable, fresh, and the twist lands at the end.

## How it works

`main.py` is deterministic, offline, and standard-library only. It writes the
fixed line above to `/output/entry.txt` (no trailing newline) and prints it.

```sh
python3 main.py
```

Two runs produce byte-identical output.
